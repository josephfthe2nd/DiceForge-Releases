# DiceForge

**A desktop studio for designing 3D-printable dice.**

Pick a shape, number it, engrave it with real fonts or your own artwork, add
print supports, and export a clean STL or 3MF — all on your machine, no
account, no servers. Engraving is true vector geometry cut with a CAD
boolean kernel, so exports are always watertight and print-ready.

## Download

Grab the latest **`DiceForge-<version>-win64.zip`** from the
[**Releases**](https://github.com/josephfthe2nd/DiceForge-Releases/releases) page,
unzip it anywhere, and run **`DiceForge.exe`**. Windows 64-bit — no Python
required. DiceForge checks for updates on launch.

## Features

- **50+ dice shapes** across eight families, each labeled fair / approximate
  / novelty, with a live balance report.
- **Reshape your dice** — stretch crystal points, shorten barrels, reshape
  teardrops; customizable dice are marked with a 🎲 in the Add die menu.
- **Vector engraving** — a themed font library (plus your own .ttf/.otf),
  pips on d6, two-tone number inlays, outlined numbers, 6/9 markers, and
  logo/image engraving.
- **Per-face & d4 control** — restyle one face, edit all faces at once, or
  edit the caltrop d4 corner by corner.
- **Print supports** — fins, pins, or trees with simulated-overhang
  detection, auto-orientation, and hand-editing; they never scar your
  numbers.
- **Export** — die only, die + supports, supports only, two-tone bodies, or
  the whole set plated. STL or 3MF.
